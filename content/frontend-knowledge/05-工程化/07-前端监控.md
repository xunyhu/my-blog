# 前端监控

## 一、是什么

通过埋点收集前端运行数据，实现问题监控与性能分析。

## 二、分类

1. 错误监控

   `window.onerror`

2. 性能监控

   `PerformanceObserver`（`performance.timing` 已废弃）

3. 用户行为
   - PV / UV
   - 点击路径

## 三、核心指标

Core Web Vitals（Google 核心指标）：

- LCP（最大内容绘制）—— 加载性能
- INP（交互到下次绘制）—— 交互响应，**2024.3 起取代 FID**
- CLS（累积布局偏移）—— 视觉稳定性

辅助指标：FCP（首次内容绘制）、TTFB、TTI（可交互时间，实验室指标）

## 四、实现方式

- 手动埋点
- 自动采集
- SDK（Sentry）

## 五、总结

前端监控本质：

数据驱动优化体验
