# 前端性能优化

## 一、核心目标

- 更快加载
- 更流畅体验

## 二、优化方向

### 1. 网络优化

- CDN
- gzip
- HTTP/2

### 2. 资源优化

- 图片压缩
- 懒加载
- 代码分割

### 3. 渲染优化

- 减少重排
- 使用 transform
- 虚拟列表

### 4. JS 优化

- 防抖节流
- Web Worker
- 减少主线程阻塞

## 三、关键指标

Core Web Vitals（真实用户体验指标）：

- LCP（最大内容绘制）—— 加载性能
- INP（交互到下次绘制）—— 交互响应，**2024.3 起取代 FID**
- CLS（累积布局偏移）—— 视觉稳定性

辅助指标：FCP（首次内容绘制）、TTFB（首字节时间）、TTI（可交互时间，实验室指标）

## 四、总结口诀

少请求、快加载、少阻塞、少重排
