# 跨域问题

## 一、是什么

浏览器同源策略限制不同源之间的请求。

## 二、什么是同源

必须同时满足：

- 协议相同
- 域名相同
- 端口相同

## 三、解决方案

### 1. CORS（推荐）

服务器设置： Access-Control-Allow-Origin: \*

### 2. JSONP（只支持 GET）

### 3. 代理（开发常用）

```js
// vite
server: {
  proxy: {
  }
}
```

### 4. postMessage

用于 iframe 通信
