# 哈希表

## 核心本质

用空间换时间，实现 O(1) 查询

## JS 对应结构

- Object
- Map
- WeakMap

## 使用建议

- 高频查找 → 用 Map
- key 为对象 → 用 WeakMap（避免内存泄漏）

## 前端典型场景

- 缓存（memoization）
- 去重
- 状态索引（id → data）

```js
const map = new Map();
map.set('id', data);
```
