# 前端知识体系模块文档

## 1. 模块概述

「前端知识体系」是博客的核心内容板块，以结构化的方式整理前端开发从基础到进阶的完整知识图谱。

**入口**: 首页卡片 → `/knowledge`
**内容规模**: 10 大分类模块，78 篇知识文章

---

## 2. 路由结构

| 路由                   | 页面         | 渲染方式 | 说明                                   |
| ---------------------- | ------------ | -------- | -------------------------------------- |
| `/knowledge`           | 知识图谱首页 | Server   | 10 大模块卡片网格，展示全部知识点目录  |
| `/knowledge/[...slug]` | 知识点详情   | Server   | 单篇知识文章，Markdown 渲染 + TOC 侧栏 |

路由示例：

```
/knowledge                              → 首页
/knowledge/01-JavaScript核心/01-数据类型  → 数据类型文章
/knowledge/04-React体系/05-Hooks原理      → Hooks 原理文章
```

> 注意：slug 中包含中文目录名，在 `getContent()` 中通过 `decodeURIComponent()` 处理。

### 命名规范

- 目录：`编号-分类名`（如 `01-JavaScript核心`），编号用于排序
- 文件：`编号-知识点名.md`（如 `01-数据类型.md`），编号决定展示顺序
- 展示时通过 `.replace(/^\d+-/, '')` 去掉编号前缀

## 5. 核心代码模块

### 5.1 数据获取 — `lib/blog.ts`

| 函数                | 作用                                                           |
| ------------------- | -------------------------------------------------------------- |
| `getKnowledgeMap()` | 读取 `content/frontend-knowledge/` 目录结构，返回分类+文章列表 |

返回数据结构：

```ts
Array<{
  title: string; // 分类名（去掉编号前缀）
  children: Array<{
    name: string; // 文章名（去掉编号前缀）
    slug: string; // 完整路径 /knowledge/分类/文件名
  }>;
}>;
```

### 5.2 内容读取 — `lib/post/getContent.ts`

| 函数                            | 作用                                                           |
| ------------------------------- | -------------------------------------------------------------- |
| `getContent('knowledge', slug)` | 根据 slug 数组拼接路径，读取 MD 文件，返回 `{ content, data }` |

关键处理：knowledge 类型的 slug 会经过 `decodeURIComponent()` 解码（因为目录名含中文）。

### 5.3 TOC 提取 — `lib/post/toc.ts`

| 函数                | 作用                                                     |
| ------------------- | -------------------------------------------------------- |
| `extractHeadings()` | 正则匹配 `#`/`##`/`###` 标题，提取 `{ level, text, id }` |

### 5.4 骨架生成 — `scripts/generate-frontend-knowledge.js`

批量生成知识体系文章骨架的脚本：

- 按 `structure` 对象定义创建目录和文件
- 每篇文章生成统一模板（是什么 → 为什么 → 核心原理 → 代码实现 → 总结）
- 文件名自动补零编号（`01-`, `02-`, ...）

### 6.2 知识点详情页 — `app/knowledge/[...slug]/page.tsx`

**渲染方式**: Server Component

````
┌─────────────────────────────────────────────────────┐
│  BackButton (固定左上角，fallback="/knowledge")       │
│                                                     │
│  ┌──────────┐  ┌──────────────────────────────────┐ │
│  │   TOC    │  │   Markdown 文章内容               │ │
│  │ (侧栏)   │  │                                  │ │
│  │          │  │   # 数据类型                      │ │
│  │ · 一、是  │  │   ## 一、是什么                   │ │
│  │ · 二、基  │  │   ...                            │ │
│  │ · 三、引  │  │   ```js                          │ │
│  │ · 四、核  │  │   // 代码示例                     │ │
│  │ · 五、su  │  │   ```                            │ │
│  │          │  │   ...                            │ │
│  └──────────┘  └──────────────────────────────────┘ │
│                                                     │
│  (TOC 在 lg 断点以下隐藏，仅桌面端显示)               │
└─────────────────────────────────────────────────────┘
````

- 使用 `ContentLayout` 组合 TOC 侧栏 + 文章内容区
- `MarkdownRenderer` 渲染 Markdown 内容（react-markdown + remark/rehype 插件链）
- `BackButton` 提供返回导航，fallback 到 `/knowledge`

## 7. 文章内容规范

每篇知识文章遵循统一结构（由骨架生成器定义）：

```markdown
# 知识点标题

## 一、是什么

概念定义与核心解释

## 二、为什么

学习意义与实际价值

## 三、核心原理

### 1. 基本概念

### 2. 执行流程

### 3. 关键点

## 四、代码实现

代码示例与演示

## 五、总结

要点回顾与进阶建议
```

> 部分已完成内容的文章（如「前端发展史」「数据类型」）在此基础上进行了扩展和细化。
