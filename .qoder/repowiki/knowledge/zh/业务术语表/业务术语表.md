### AI 工程师知识板块
- 定义：博客中独立于传统 blog 分类的知识体系，位于 `content/ai-engineer/`，按主题分 7 个一级目录（AI基础、工程化实践、RAG、Agent、MCP、产品与架构等），对应路由 `/ai-engineer/[...slug]`，由 `lib/blog.ts` 中的 `getAIEngineerMap` 驱动渲染。
- 别名：ai-engineer、AI 工程师板块

### Wave 0
- 定义：产品经理 Agent 迭代计划中的第一个开发阶段，用于启动后续内容完善工作。
- 别名：wave 0

### knowledge 卡
- 定义：存放在 `.qoder/knowledge/` 下的结构化知识条目，用于沉淀项目上下文（如 `knowledge-module.md`、`project-architecture.md`），供 Qoder Agent 在对话中检索。
- 别名：knowledge、知识卡

### prds
- 定义：存放在 `.qoder/prds/` 下的需求文档目录，存放面向 Agent 的产品需求说明（如 `ai-engineer.md`）。
- 别名：prd、PRD

### skill
- 定义：Qoder 的可复用能力定义，放在 `.qoder/skills/<name>/SKILL.md`，通过斜杠命令（如 `/git-commit`）被 Agent 加载执行，描述任务流程、规范和约束。
- 别名：SKILL.md、技能

### git-commit skill
- 定义：本项目自定义的 Git 提交流程 skill，约定 Conventional Commits（feat/fix/docs/refactor 等 type）、中英混合提交信息、默认分支 master、禁止自动 push，并在 commit 前主动运行 `npx tsc --noEmit` 避免 husky 钩子失败。
- 别名：/git-commit

### 产品经理 Agent
- 定义：用户要求为该项目新增的角色型 Agent，目标是阅读项目 knowledge 后迭代后续内容、完善博客网站。
- 别名：PM Agent、product-manager agent
