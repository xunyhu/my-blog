采用 Next.js App Router 的目录路由结构：`app/blog/page.tsx` 为全量文章入口，`[category]/page.tsx` 按分类筛选，`[category]/[tag]/page.tsx` 叠加标签筛选，`post/[...slug]/page.tsx` 通过 catch-all 路由加载任意路径的文章内容。
- 数据层：所有页面统一从 `@/lib/blog` 的 `getAllPosts` 读取静态文章，再经 `@/lib/utils` 的 `filterPosts`、`getTagsByCategory` 做客户端侧过滤；文章正文由 `@/lib/post/getContent` + `@/lib/post/toc` 解析。
- 视图层：页面组件仅负责组装布局与调用数据函数，UI 抽离到 `app/components/blog/` 下的纯展示组件（`CategoryNav`、`TagFilter`、`PostCard`），复用 Tailwind 原子类完成样式。
- 类型边界：`Category`、`Post`、`Tag` 等类型来自 `@/types/blog`，`CATEGORY_CONFIG` 来自 `@/config/category`，路由参数使用 Promise 形式的 `params` 并显式声明类型。
- 依赖方向单向：pages → components/blog → 外部配置/类型；文章详情页额外依赖 `@/app/components/post/*` 复用通用 Markdown 渲染能力。
