- 页面组件统一以 async function 形式导出，并通过解构 `await params` 获取路由参数，同时用 TS 接口声明参数类型。
- 文章列表页遵循相同骨架：先 `getAllPosts()`，再用 `filterPosts` 按 category/tag 过滤，最后将结果映射为 `<PostCard>`。
- 导航组件（CategoryNav、TagFilter）通过 props 接收 `currentCategory` / `currentTag`，并以条件 class 切换高亮态，未命中时返回 null。
- Link 跳转统一使用相对路径 `/blog/...`，并在 PostCard 中通过 `?from=referrer` 查询串回传来源分类。
- 样式全部以内联 Tailwind class 字符串书写，不使用外部 CSS 文件或 CSS-in-JS。
