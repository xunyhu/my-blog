以 `app/` 作为 Next.js App Router 根目录，按功能域拆分子路由：`blog/`（文章列表与详情）、`knowledge/`（知识库）、`ai-engineer/`（AI 工程师介绍）、`projects/`（项目展示），由 `app/layout.tsx` 提供全局布局与元信息，`app/page.tsx` 作为首页入口。

跨子路由的复用通过以下边界解耦：
- `app/components/` 存放客户端 React 组件（粒子背景、目录导航、文章卡片、Markdown 渲染等），被各页面直接 import；
- `app/hooks/useActiveHeading.ts` 提供滚动高亮目录的 Hook，被详情页与知识页共用；
- `types/blog.ts` 集中声明博客相关 TypeScript 类型，供 blog_route 与 post_route 共同消费；
- `app/data/projects.ts` 为项目页提供静态数据源。

子模块之间不直接互相 import，而是通过 Next.js 路由约定与共享的 components/types 目录进行松耦合协作。
