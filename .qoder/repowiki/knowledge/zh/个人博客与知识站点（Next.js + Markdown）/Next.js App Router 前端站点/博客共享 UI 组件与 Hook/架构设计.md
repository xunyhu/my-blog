模块按用途分为两层：`app/components/` 下是展示型 React 组件，按领域再分子目录 `blog/`（PostCard、CategoryNav、TagFilter）和 `post/`（BackButton、ContentLayout、MarkdownRenderer），顶层放置全局装饰性组件 HeroParticles、HomeButton、TOC；`app/hooks/` 仅包含 `useActiveHeading.ts` 这一条可复用 Hook，被 TOC 通过相对路径 `../hooks/useActiveHeading` 引用。组件均为 Next.js 客户端组件（以 `'use client'` 或 `"use client"` 指令标记），样式统一使用 Tailwind CSS 类名，路由跳转走 Next 的 `<Link>`，Markdown 渲染链由 react-markdown + remarkGfm + rehype-highlight/slug/autolink-headings 组合而成，外部依赖方向单向：组件 → hooks，无反向引用。
