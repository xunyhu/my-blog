- 所有需要浏览器 API 的组件与 Hook 在文件顶部显式声明 `'use client'` 指令（如 HeroParticles、TOC、useActiveHeading、MarkdownRenderer）。
- 组件默认导出函数式组件，props 通过解构参数并以内联 `{}` 类型注解声明（如 PostCard、MarkdownRenderer）。
- 样式全部采用 Tailwind CSS 原子类拼接，不使用独立 CSS 文件或 CSS-in-JS。
- 内部路由跳转统一使用 Next 的 `<Link>` 组件而非原生 `<a>`，外部链接才降级为原生 `<a target="_blank">`。
