采用 Next.js App Router 约定式路由：`app/layout.tsx` 作为 RootLayout 提供 `<html>`/`<body>` 外壳，并通过 `export const metadata` 声明站点标题模板（`%s | HuRui.dev`）与描述；`app/page.tsx` 是异步 Server Component 首页，通过 `@/lib/blog` 的 `getAllPosts()` 在渲染期拉取数据，再组合 HeroParticles、技术栈标签、知识体系/项目/AI Engineer 三大导航卡片以及最新博客列表。`types/blog.ts` 集中定义跨层共享的类型契约 `Category`、`Tag`、`Post`，被 `page.tsx` 直接 import 使用。样式层面，`app/globals.css` 由 layout 引入，配合 Tailwind CSS 的 `dark:` 前缀实现明暗主题切换。依赖方向单向向下：页面组件 → lib 数据层 + types 类型层，无反向引用。
