模块由三个独立的 'use client' 组件组成，职责单一且互不依赖：
- BackButton.tsx：通过 next/navigation 读取 searchParams.from，委托给 @/lib/navigation/getBackPath 计算回跳路径后 router.push。
- ContentLayout.tsx：组合 TOC（@/app/components/TOC）与 children，使用 Tailwind 的 hidden lg:block 实现桌面端目录侧边栏、移动端隐藏；article 区域通过 prose 类交由 tailwindcss/typography 排版。
- MarkdownRenderer.tsx：基于 react-markdown + remark-gfm + rehype-highlight/slug/autolink-headings 构建渲染管线，并通过 components 自定义 a 标签（站内 / 前缀走 Next.js Link，外部链接 target=_blank rel=noopener）和 table 容器。
依赖方向单向向外：仅消费 @/lib/navigation/* 与 @/app/components/TOC，不暴露内部状态或业务逻辑。
