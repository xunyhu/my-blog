模块按职责拆分为三个子目录：
- `lib/blog.ts`：核心入口，基于 `fs` + `gray-matter` 递归扫描 `content/blog`、`content/frontend-knowledge`、`content/ai-engineer` 三类 Markdown 源，导出 `getAllPosts`、`getAllCategories`、`getAllTags`、`getKnowledgeMap`、`getAIEngineerMap` 等聚合 API。
- `lib/post/`：内容读取与渲染辅助，`reader.ts` 封装统一的 `getFileContent`（返回 `{ content, data }`），`getContent.ts` 根据类型映射到对应 `content/*` 目录并拼接 slug，`toc.ts` 用正则提取 h1-h3 生成目录结构。
- `lib/navigation/getBackPath.ts`：维护 `from -> URL` 的白名单映射，用于详情页返回上一页。
- `config/category.ts`、`config/tag.ts`：纯常量配置，集中声明分类与标签的 label/color 元数据。
依赖方向单向：`post/*` 依赖 `reader.ts`；`blog.ts` 直接操作 fs 和 matter；`utils.ts` 仅消费 `types/blog` 中的 `Post`、`Category` 类型做过滤与格式化；所有文件均不反向依赖业务页面。
