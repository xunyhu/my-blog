三个相互独立的 Node ESM 脚本，均基于 `fs`/`path` 操作 `content/` 下的 Markdown 文档：
- `generate-ai-engineer.js`：按内置的 `structure` 映射（00-AI基础 ~ 07-产品与架构）在 `content/ai-engineer/<category>/NN-标题.md` 下生成占位文章；`00-AI基础` 使用 `generateBasicContent` 模板，其余使用带代码块与工程实践章节的进阶模板。
- `generate-frontend-knowledge.js`：对 `content/frontend-knowledge` 执行相同流程，模板更简洁，并提供可选的 `cleanDir` 清空旧目录能力（默认注释掉）。
- `inject-frontmatter.js`：双板块共用，遍历上述两个目录，从正文解析 h1、首个实质段落、文件行数等，生成包含 `title/description/updatedAt/module/order/status` 的 YAML frontmatter；支持 `--dry-run` 预览模式，且对所有写入路径做幂等守卫——已存在 frontmatter 或已有 `.md` 文件的脚本一律跳过。
依赖方向单向：脚本 → 文件系统 → `content/` 下的 Markdown 源文，脚本之间无互相引用。
