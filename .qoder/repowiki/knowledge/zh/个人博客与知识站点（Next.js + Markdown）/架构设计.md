根目录作为单仓入口，通过 package.json 的 scripts（dev/build/start/lint/prepare）统一驱动子模块：app_pages 提供 Next.js 应用壳与路由；content_knowledge_base 以 Markdown 归档内容；lib_utils 在构建期读取这些 Markdown 并生成分类、标签、目录树等数据供 app_pages 渲染；build_scripts 在开发前批量生成知识库骨架文章。运行时依赖 gray-matter、remark/rehype 系列插件解析 Markdown，Tailwind CSS 4 与 @tailwindcss/typography 统一样式，framer-motion/reactflow 提供交互组件。husky + lint-staged 在 git commit 阶段对 ts/tsx 执行 tsc --noEmit 与 next lint --fix，保证跨子模块的代码质量一致。
